# S.M.HP シンプルプラン(3ページ)ブラック × オレンジ配色版

株式会社RN板金工業の既存サイト(https://rnbankin19.com/)の情報をもとに制作した、
ホームページテンプレート「シンプルプラン」の修正版です。

## ページ構成

| ファイル | 内容 | プランのページ数 |
|---|---|---|
| `index.html` | TOP | 1 |
| `service.html` | 事業内容(断熱・保温・保冷工事/板金加工・施工/ダクト取付工事) | 2 |
| `company.html` | 会社概要・アクセス(地図)・お問い合わせフォーム | 3 |
| `privacy.html` | プライバシーポリシー(補助ページ。ページ数に含めない) | — |

```
S.M.HP_カラー変更_ブラックオレンジ/
├─ index.html / service.html / company.html / privacy.html
├─ assets/
│  ├─ css/style.css   … 共通デザイン(色は先頭の :root で一括変更)
│  ├─ js/main.js      … スマホメニュー、ページ遷移時の表示位置、ページトップ等
│  └─ img/            … 写真
└─ README.md
```

## プレビュー方法

- いちばん簡単:フォルダ内の `index.html` をダブルクリックしてブラウザで開く。
- ローカルサーバーで確認する場合(Python が入っているPC):
  ```
  cd S.M.HP_カラー変更_ブラックオレンジ
  python -m http.server 8000
  ```
  ブラウザで http://localhost:8000/ を開く。
- Googleマップと Webフォント(Noto Sans JP など)はインターネット接続時に表示されます。
  フォントが読み込めない環境では、PC標準の日本語フォントで表示されます。

## 配色(ブラック × オレンジ × ホワイト)

`assets/css/style.css` 冒頭の `:root` で管理しています。ブルー系の色は使っていません。

| 用途 | 変数 | 色 |

| メイン(ヘッダー・見出し・濃い背景・通常ボタン) | `--c-main` | `#252525` |

| アクセント(お問い合わせボタン・ライン・アイコン) | `--c-accent` | `#E98232` |
| オレンジのホバー | `--c-accent-dark` | `#D06F22` |
| メイン背景 | `--c-bg` | `#FFFFFF` |
| サブ背景 | `--c-sub-bg` | `#F4F4F2` |
| 本文 | `--c-text` | `#333333` |
| 補助(補足情報・控えめな装飾) | `--c-muted` | `#777777` |

## ページ遷移時の表示位置(assets/js/main.js)

- ヘッダーのメニュー・ロゴで別ページへ移動したとき:移動先ページの最上部から表示
- `company.html#contact` など見出し付きのリンク:その見出しへ移動(固定ヘッダーに隠れないよう余白を確保)
- ページ内リンク(TOPの「主な事業内容」「施工写真」、事業内容ページの目次):該当セクションへ移動
- ブラウザの戻る・進む:そのページで見ていた位置に戻す

ブラウザの自動復元(`history.scrollRestoration`)を `manual` にし、上記の動作を `main.js` で制御しています。

## 差し替え項目(顧客ごとに変更する所)

- **色**:`assets/css/style.css` 冒頭の `:root`
- **会社名・住所・地図**:各HTMLの該当箇所。地図は `company.html` の iframe の `q=` に住所(URLエンコード)を入れる
- **電話番号・メールアドレス**:既存サイトに掲載がないため未記入。`class="replace-slot"` の箇所を実際の値に置き換える
- **プライバシーポリシー制定日**:`privacy.html` の `replace-slot`
- **ファビコン**:各HTMLの `<head>` のコメントを外して `assets/img/favicon.png` を置く

## お問い合わせフォームについて

見た目のみのデザイン見本です。送信機能は実装していません(送信ボタンは無効化、送信完了の表示もしません)。
公開時に送信サービスを設定する場合は、`company.html` の `<form>` の `action` と送信ボタンの `disabled` を変更し、
`privacy.html` の「4. 外部サービスの利用」に追記してください。
